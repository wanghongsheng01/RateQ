# RateQ

Exact cheapest-service queries and incremental maintenance over rule-defined shipping rate cards.

This repository accompanies the ICDE 2027 submission "RateQ". It will contain the index and query engine (Python reference and C++ core), all baselines, the parsers for the official 2026 UPS, FedEx and USPS rate data, the synthetic workload generators, the experiment scripts and the result tables.

Enterprise rate cards and parcel records used in the paper are de-identified company data and are not distributed; only aggregate results are reported.
